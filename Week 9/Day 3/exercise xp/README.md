# Daylist — Redux Toolkit Todo List

A Week 9 Day 3 XP exercise built with React, React Redux, and Redux Toolkit.

## Run the app

```sh
npm install
npm run dev
```

## Features

- Add non-empty tasks.
- Mark tasks complete or active and remove tasks.
- Filter the list by all, active, or completed tasks.
- Keep todo state in a Redux Toolkit slice and provide the store with React Redux.
