# Daybook — Daily Planner

A Week 9 Day 3 daily planner exercise built with React, React Redux, and Redux Toolkit.

## Run the app

```sh
npm install
npm run dev
```

## Features

- Choose a day from the weekly date picker, navigate between weeks, or jump directly to a date.
- Add tasks to a selected day with optional time and notes.
- Edit or delete tasks for that day.
- View tasks in time order, with unscheduled tasks at the end.
- Keep task data organized in Redux Toolkit by `YYYY-MM-DD` date key.
