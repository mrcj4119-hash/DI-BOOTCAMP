# Stockroom — Redux Toolkit Inventory

A Week 9 Day 3 XP Ninja exercise using React, React Redux, and Redux Toolkit.

## Run the app

```sh
npm install
npm run dev
```

## Features

- View sample products, prices, categories, and stock levels.
- Add products with a name, category, price, and starting quantity.
- Adjust stock with quantity controls; quantities cannot drop below zero.
- Remove products and see inventory totals update immediately.
- Manage product data through a Redux Toolkit slice and React Redux store.
