# Goodwell — Redux Toolkit Authentication

A Week 9 Day 3 XP Gold exercise using React, React Redux, and Redux Toolkit.

## Run the app

```sh
npm install
npm run dev
```

## Features

- Manage authentication status and user information in an auth slice.
- Sign in and sign out through Redux actions.
- Render the sign-in form or authenticated welcome screen based on Redux state.
- Demonstrate client-side authentication only; no credentials are verified or sent to a server.
