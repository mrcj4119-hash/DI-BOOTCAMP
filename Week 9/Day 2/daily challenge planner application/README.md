# Daybook — Daily Planner

A Week 9 Day 2 daily planner exercise built with React and Redux.

## Run the app

```sh
npm install
npm run dev
```

## Features

- Navigate by week, select a day, or jump directly to a date.
- Add tasks with an optional time and note.
- Edit or delete tasks for the selected date.
- Tasks are stored in Redux under their `YYYY-MM-DD` date key.
- Planner tasks persist across reloads in browser local storage.
- Invalid task actions and browser storage errors are shown in the interface.
