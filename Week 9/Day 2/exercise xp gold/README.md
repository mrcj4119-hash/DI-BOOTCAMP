# Little List — Categories

A Week 9 Day 2 XP Gold exercise using React and Redux to organize todos into categories.

## Run the app

```sh
npm install
npm run dev
```

## Features

- Starter categories for Work, Personal, and Learning.
- Create additional categories from the sidebar.
- Add, complete, and remove tasks in the currently selected category.
- See category task counts and overall completion progress.
- Redux actions and reducers update category and todo data immutably.
- Clear error feedback for duplicate categories and invalid category/task actions.
